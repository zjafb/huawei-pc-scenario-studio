# 当前版本验收（无需阅读代码）

范围以最新用户要求为准：55个产品、四渠道、8类场景，已取消双人签字门槛。10个完整规格档案与45个发现卡应区分显示；缺图如实提示。

1. 电脑端左侧输入、右侧结果；手机上下排列，没有横向溢出。
2. 搜索选择型号、人群、场景、渠道；展开内容设置，可设置图片数、详略、修订和资料模式。
3. 点击生成，节点随真实任务推进。失败显示具体原因，不用固定稿替代失败。重试最多三次真实模型调用。
4. 查看原文依据与核验素材，对照引用、配置条件、画面及来源；发现卡不得冒充完整规格。
5. 展开复制与下载，测试复制、TXT、离线图文HTML；导出应有实际图片和来源。
6. 填入修订要求再生成，应使用同型号上一稿；切换核心需求后旧稿、下载和引用应清空。
7. 用Tab和Enter操作控件、标签、执行节点和导出。焦点清晰；动效开关和系统减少动态效果有效。
8. 无依据价格、补贴、保证不得进入可发布稿。规则不能穷尽语义风险，发布前仍需人工核对。

自动检查：`python tools/run_checks.py`，禁止真实连接器联网，合成测试不能作参赛运行成果。
真实验收：`python tools/check_full_flow.py --run`，会调用模型并保存实际记录。
