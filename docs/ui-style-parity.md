# 场景创作室：真实界面的视觉一致性修复

保留真实 Gradio 工作流，将已选定的纸感设计适配到实际组件；不是独立模拟页面。

## 修复内容

- 避免 Gradio 外壳与后续样式覆盖背景：暖白底色、陶土色光晕、鼠尾草绿渐变完整延伸到页面底部。
- 使用现有本地 Noto Sans SC / Noto Serif SC，字重范围与实际字体一致；不加载外部字体。
- 顶端高光、内边缘、环境阴影、进度卡片和三层叠纸结果区，与选定设计保持一致。
- 陶土渐变主按钮、悬停光泽、按压反馈；进度节点呼吸和光环、结果入场、空态浮动徽章与等待骨架。
- 桌面指针支持输入卡片局部光照与真实产品图片的轻微透视，正文不倾斜。
- 保留动效开关和系统减少动态效果；手机关闭指针效果。
- 进度只读取后台真实事件。开始最终核验时仍未完成，只有收到实际合格或受限结果才显示完整进度。

样式通过 `StudioBlocks.launch()` 统一注入，本地 `run.py` 与魔搭 `app.py` 共用同一套资源。

## 资源

- `app/assets/studio.css`、`studio.js`：已有兼容样式与控件指示线。
- `app/assets/studio-polish.css`、`studio-effects.js`：最终视觉与交互动效层。
- `app/studio.py`：字体、样式、脚本注入与真实进度渲染。

没有修改模型额度处理、内容生成、资料权限和核验放行规则。公开仓库不包含原文、原图、凭证或实际运行记录。
