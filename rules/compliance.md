# 合规规则（违规词库与判定方式）

本文件是业务规则，团队可直接修改。程序按它检查软文和用户的额外要求。
手册要求识别五类风险：绝对化宣传、虚假承诺、无依据对比、价格误导、竞品贬低。另加两类本方案补充：伪造体验、无依据数字。

## 处理方式
每一类的处理动作不同：
- 拦截：整条请求或整句不能写，必须说明原因（用户要求违规时用）。
- 改写：删除违规词，换成有依据的表达；改写后仍需重新核验。
- 待确认：无法判断，列入核验报告，不进入正文。

---

## 类别 1：绝对化宣传（动作：改写）
含义：用“最”“第一”等无法证明的极限词。
词库（出现即命中）：
全网最、全国最、行业最、史上最、业内最、最轻、最薄、最强、最快、最好、最佳、最适合、最便宜、最实惠、第一、No.1、顶级、顶尖、极致、完美、无敌、碾压、独一无二、唯一、绝无仅有、领先同行、遥遥领先、秒杀、吊打、zui
说明：“最”字不是一律违规（如“最后一个”“最近”），程序需看上下文；程序命中“最 + 形容词/性能词”才判违规。

## 类别 2：虚假承诺（动作：改写或拦截）
含义：对结果、效果、售后作出白名单里没有的保证。
词库：
保证、一定、绝对、百分百、100%保证、包过、永久、终身、无限、零故障、永不卡顿、永远流畅、不卡顿、不发热、不会坏、包退、包换、无条件退、全国联保（除非白名单有）、秒开、一键解决、必买
说明：“100% sRGB”是白名单里的色域参数，**不是承诺**，不得误杀。判断依据：数字后面紧跟 sRGB/NTSC 且在白名单事实中。

## 类别 3：价格误导（动作：拦截）
含义：出现任何价格、补贴、优惠、权益，而白名单里没有。
词库与模式：
价格、售价、现价、原价、特价、低至、仅需、只要、立减、直降、满减、优惠、折扣、折、补贴、国补、政府补贴、以旧换新补贴、学生优惠、教育优惠、赠品、赠送、送、免息、分期、0元、元起、￥、¥、RMB、限时、秒杀价、活动价、到手价、性价比之王
模式：数字 + “元”；数字 + “折”；“立减”+数字。
处理：用户要求加入这些内容，而白名单里没有 → 拦截，原因写：“知识库中没有已批准的价格或补贴依据，不能写”。
说明：只在白名单里有已批准价格事实时才允许，并须附资料标题。初赛白名单没有价格，所以一律拦截。

## 类别 4：无依据对比（动作：改写）
含义：与上一代、其他型号、其他品牌比较，但没有已批准的对比事实。
词库与模式：
比上一代、比前代、比旧款、比去年、更轻、更薄、更快、更强、更长、提升了、升级了（无具体事实时）、超越、胜过、优于、强于、碾压、不输
处理：改成只陈述本产品的已批准事实，不比较。
说明：型号对比（如 D 14 与 D 16）只有在两边都有已批准事实、且陈述的是各自的事实时才允许，不得写“哪个更好”。

## 类别 5：竞品贬低（动作：拦截）
含义：贬低其他品牌、型号或产品。
词库：
苹果不行、比苹果、对比苹果、MacBook 不如、联想不如、戴尔不如、小米不如、竞品太差、别家、其他品牌都、别的电脑、劣质、垃圾、智商税、坑
处理：拦截并说明“不得贬低或比较竞品”。
说明：提到竞品名称本身不一定违规；与之比较或贬低才违规。初赛策略：正文不提任何其他品牌。

## 类别 6：伪造体验（动作：拦截，仅小红书和涉及用户评价时）
含义：编造个人使用经历、用户评价、销量、奖项。
词库：
我用了、我买了、我入手、入手后、亲测、实测、真实体验、使用一个月、用了半年、我同学、我室友、朋友推荐、好评如潮、满分好评、销量第一、爆款、热销、畅销、榜首、获奖、荣获、权威认证、专家推荐、老师推荐、学校指定
处理：拦截；用泛指表达替换（如“很多新生会担心……”）。

## 类别 7：无依据数字与性能（动作：拦截或待确认）
含义：正文里出现的“数字 + 单位”，在白名单事实里找不到对应。
检查对象：小时、分钟、秒、倍、%、GB、TB、Wh、W、kg、g、mm、英寸、nits、Hz、MHz、GHz、核、代
处理：
- 数字 + 单位若能对应到已批准白名单事实、且型号配置范围匹配 → 通过。
- 对应不上 → 拦截或删除，并写“该数据无已批准依据”。
- 结构性数字（“三个选购问题”“两个原因”）不检查。
特别拦截：
- 把 56 Wh 换算成续航小时数。
- 把“约 1.39 kg”写成“1.39 kg”（丢掉“约”）。
- 把标准版色域用在 SE 版，或相反。
- 把 Windows 专属功能写给 Linux 版。

## 类别 8：医疗、健康、护眼功效（动作：改写）
含义：声称护眼、保护视力、防近视等医疗性效果。
词库：护眼、保护视力、防近视、不伤眼、缓解疲劳、治疗、改善视力
说明：资料里有“显示管理（护眼模式）”作为系统功能名称，可以按功能名陈述，但不得写成对视力的功效。

---

## 判定顺序
1. 先查用户额外要求：含价格/补贴/贬低/绝对化 → 先拦截或改写，并记录原因。
2. 再查生成的正文：逐类扫描，列出命中的词、所在句、类别、处理动作。
3. 命中“拦截”类且无法改写 → 任务状态为“已拦截”。
4. 命中“改写”类 → 自动改写后重新核验；重新核验仍命中则标“待确认”，不进入正文。

## 不得误杀（正常内容）
下列内容属正常，规则不能拦截：
- “三个选购问题”“两个理由”（结构性数字）
- “约 1.39 kg”“14 英寸”“16:10”（已批准事实，带限定）
- “100% sRGB”“45% NTSC”（已批准色域参数）
- “56 Wh（额定容量）”
- “最后一个要定的装备”“最近很多新生在问”（“最”不是比较级）
- “到店看看”“留言咨询”
- “依配置不同，请以实际销售版本为准”
