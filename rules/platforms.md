# 平台规则（初赛：门店朋友圈、小红书）

本文件是业务规则，团队可直接修改。程序按它检查"结构、语气、图片数量、行动引导"是否真的不同。
手册判断标准：换平台后，结构、语气、图片数量、行动引导必须改变；只改字数或平台名不算适配。

---

## 平台一：门店朋友圈

定位：门店导购或店长发给附近熟人和顾客的一条消息，目的是让人想来店里看看或来问一句。
手册要求：短文案、一个核心卖点、咨询或到店引导；1–3 张图，优先主图与场景图。

结构（必须按顺序）：
1. 一句钩子（场景化，不是参数）
2. 一个核心卖点（只一个；附一个事实，带限定条件）
3. 一句行动引导（咨询或到店）

硬规则：
- 正文总长约 60–120 字。
- 核心卖点**只能有一个**，出现第二个卖点即不合格。
- 不用话题标签。
- 不超过 2 个表情符号，或不用。
- 语气：像店员对熟客说话，直接、有人情味，不夸张，不长篇。
- 行动引导只能是"来店体验""留言咨询""私信问问"这类，**不得含价格、活动、限时、库存**。
- 图片：1–3 张。有合格图就 1 张；不够 1 张则状态为“受限”。
- 图片说明：一句话，说明图里是什么，以及为什么放在这里。

不合格情形（强制）：
- 出现 2 个及以上卖点。
- 出现话题标签。
- 出现未批准的产品参数。
- 出现“限时”“抢”“最后”“仅剩”等紧迫催促，除非白名单里有明确的活动事实。

示例结构（仅展示格式，不是可用文案）：
```
【钩子：场景一句话】
【一个卖点：事实 + 限定条件】
【引导：来店 / 留言】
```

## 平台二：小红书

定位：面向陌生人的分享类内容，靠场景代入和实用信息吸引收藏。
手册要求：口语化标题、短段落、使用场景、话题标签；3–6 张图；不得伪造个人体验。

结构（必须按顺序）：
1. 口语化标题（带一个场景或疑问，不堆参数）
2. 开头：交代“谁在什么情况下”的一句话（用第三人称或泛指，不用“我”）
3. 3–4 个短段落，每段一个小标题或一个要点，对应 2–4 个卖点
4. 选购提醒段（提示版本、配置、需到店确认）
5. 行动引导（评论区交流 / 到店看看）
6. 话题标签 4–6 个

硬规则：
- 正文约 250–450 字。
- 段落短，每段 2–3 句。
- 语气：轻松、口语、有节奏，像在跟朋友分享攻略，但不夸张。
- **禁止第一人称体验**：不写“我用了”“我买了”“我同学”“亲测”“实测”“入手后”。可以写“如果你是……”“很多新生会……”。
- 话题标签只用与产品和场景相关的，不带品牌营销口号。
- 图片：需 3–6 张，每张写来源、说明、建议插入位置。
- 图片不足 3 张：状态为“受限”，顶部标红“未满足平台要求：需 3 张，仅有 N 张”。**不得借图、不得重复图凑数。**
- 行动引导：软性，不催促，不含价格与活动。

不合格情形（强制）：
- 出现第一人称体验或“亲测”类词。
- 出现话题标签少于 4 个。
- 出现未批准的产品参数。
- 编造用户评价、销量、榜单。

## 两个平台的实质区别（验收时对照）

| 项目 | 门店朋友圈 | 小红书 |
|---|---|---|
| 目的 | 让熟人想到店 | 让陌生人收藏、讨论 |
| 结构 | 钩子 + 1 卖点 + 引导 | 标题 + 开头 + 多段 + 选购提醒 + 引导 + 标签 |
| 卖点数 | 只能 1 个 | 2–4 个 |
| 篇幅 | 约 60–120 字 | 约 250–450 字 |
| 语气 | 店员对熟客，直接 | 分享攻略，轻松口语 |
| 图片 | 1–3 张 | 3–6 张 |
| 标签 | 无 | 4–6 个 |
| 行动引导 | 来店 / 留言咨询 | 评论交流 / 到店看看 |
| 人称 | 可用“我们店”“来店里” | 禁止个人体验第一人称 |

## 当前初赛支持范围
- 支持：门店朋友圈、小红书。
- 暂不支持：公众号、门店海报（手册要求的平台，初赛如实不做，说明书里写明）。
