# 场景库（初赛：开学季、职场差旅）

本文件是业务规则，团队可直接修改。程序读取它来决定"这次该怎么写"。
重要约束：场景库只能决定"切入点、卖点取舍顺序、语气"，**不能提供任何产品事实**。产品事实只能来自已批准的白名单。

## 如何使用
- 每个场景给出：人群、核心问题、购买阶段、内容目标、切入点、卖点优先级、禁说。
- 卖点优先级写的是"关注类别"（便携、接口、屏幕、系统……），不是具体数字。程序再到白名单里找该类别下已批准的事实；找不到就不写这个卖点，并在核验报告里说明"该类别无已批准事实"。
- "禁说"是强制拦截项，优先级高于生成。

## 场景一：开学季（大学新生）

人群：刚考上大学、要自己买第一台笔记本的新生；也包括替孩子挑选的家长（家长另起切入点，见下）。
核心问题：
1. 课程、作业、论文都要用，不知道选什么级别够用。
2. 每天背着去教室、图书馆，怕太重。
3. 预算有限，怕买贵、怕买错。
4. 宿舍、教室的外设和投影接口兼容问题。
购买阶段：已决定要买电脑，在比较型号、纠结要不要到店看。
内容目标：让新生觉得"这款适合我的日常学习"，并愿意到店亲手摸一下。

切入点（二选一，按平台选）：
- A. "开学前最后一个要确定的装备"：从日常学习场景出发，而不是堆参数。
- B. "每天背着走的那台电脑"：从携带和接口出发。

卖点类别优先级（从高到低）：
1. 便携（重量、机身尺寸类事实）
2. 接口（HDMI、USB 数量等，对应教室投影和外设）
3. 屏幕（尺寸、比例，对应看文档和网课）
4. 电池容量（只说容量，不说续航小时数）
5. 系统与自带应用（仅限已批准且标明 Windows 的应用）

家长版（若人群写"家长"）：
- 切入点换成"孩子用几年的实用性与售后到店方便"，语气更稳重，少用网络用语。
- 卖点次序前移：接口实用性、系统稳定性说明；后移：外观与屏幕观感。
- 仍然不得出现价格、补贴、分期、优惠承诺。

禁说（强制拦截）：
- 任何价格、补贴、国补、学生优惠、分期、赠品，除非白名单里有明确的已批准事实。
- "全网最轻""最适合大学生""学习神器""性能强劲到不卡"。
- 把"56 Wh"换算成"可用多少小时"。
- 暗示已被某学校或老师采用、推荐。
- 编造学生口吻的使用体验（如"我用了一学期"）。

## 场景二：职场差旅（商务人士、经常出差者）

人群：经常出差、在会议室和路上办公的职场人；多为已有电脑、想换一台更轻便的。
核心问题：
1. 带出门是否轻便，是否方便放进随身包。
2. 会议室投屏接口是否够用，要不要带转接头。
3. 在不同地点连接外设、办公的稳定性。
4. 担心换新机后文件和习惯迁移麻烦。
购买阶段：已有设备，有换机想法，在对比型号。
内容目标：让对方觉得"这台适合我出差的节奏"，并愿意咨询或到店了解。

切入点：
- A. "出差包里的那一件"：围绕携带和接口，不是围绕学习。
- B. "不用再带转接头"：围绕接口配置（仅限已批准的接口事实）。

卖点类别优先级（从高到低）：
1. 接口（HDMI 等，对应投屏）
2. 便携（重量、机身厚度类）
3. 屏幕（尺寸、比例，对应多文档并排）
4. 系统与自带应用（Windows 专属功能，保留"仅限 Windows 版本"）
5. 电池容量（只说容量，不说续航小时数）

与开学季的实质区别（验收要点）：
- 切入点不同（学习日常 vs 出差节奏）。
- 卖点第一位不同（便携 vs 接口）。
- 语气不同（亲切、同龄 vs 简练、务实）。
- 行动引导不同（来看看开学装备 vs 咨询选型/到店了解）。

禁说（强制拦截）：
- 任何价格、补贴、企业采购价、批量折扣、售后保障承诺，除非白名单里有。
- "商务精英首选""出差必备""效率翻倍""全天续航"。
- 声称与具体办公软件兼容、会议软件体验优秀，除非有已批准事实。
- 安全性相关承诺（防窃、加密）——白名单里没有，不写。
- 贬低其他品牌或型号。

## 通用规则（两个场景都适用）

1. 场景描述句和行动引导可以有结构性数字（如"三个选购问题"），不得出现未经白名单支持的产品参数。
2. 场景推断句要用"可能""很多人"这类措辞，不能写成对事实的断言。
3. 所有场景都必须保留产品事实的限定条件：“约”“依配置不同”“仅限 Windows 版本”“典型值”。
4. 型号与版本不明时，不写依赖版本的事实（如色域、键盘背光）。
5. 如果某个优先级类别下没有任何已批准事实，就跳过，不要用空话填充。
6. 场景库只用于策略，不得原样作为宣传文案输出。
